# easy-python
Simple Python examples and exercises for beginners


This repository contains a series of small Python projects, organized from easiest to hardest.  
Each project is numbered from 1 to 4 to show its difficulty level.

## Projects

1. **Paint (simple version)** – a very basic drawing program  
2. **Password Generator** – generates random passwords (includes an HTML version)  
3. **Snake Game** – the classic snake game made with Python  
4. **Calculator with UI** – a calculator built with a graphical user interface
